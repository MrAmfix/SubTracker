# SubTracker

SubTracker - Android-приложение для учета платных подписок, контроля ближайших списаний и оценки регулярных расходов в выбранной валюте.

Приложение помогает хранить список активных и неактивных подписок, видеть суммы по всем сервисам, получать напоминания о платежах, учитывать разные периоды оплаты и делать резервные копии данных в JSON.

## Возможности

- Добавление, редактирование и удаление подписок.
- Включение и отключение подписок без удаления из истории.
- Учет названия, описания, стоимости, валюты, даты следующего платежа и иконки/фото подписки.
- Поддержка разных правил оплаты:
  - еженедельно;
  - каждые N дней;
  - каждый месяц в выбранное число;
  - ежегодно;
  - произвольный интервал в днях.
- Автоматический расчет ближайшей даты платежа на основе правила оплаты.
- Сортировка списка по дате оплаты, стоимости и названию.
- Сводка расходов по активным и всем подпискам.
- Конвертация сумм в основную валюту.
- Получение курсов валют через API ЦБ РФ и кеширование курсов.
- Поддерживаемые валюты: RUB, USD, EUR, JPY, CNY.
- Экран статистики с итогами, курсами валют и расчетом подписок по периодам выплат.
- Настройка дней зарплаты и аванса для группировки платежей.
- Напоминания о платежах:
  - в день оплаты;
  - за 1 день;
  - за 3 дня;
  - за 7 дней.
- Светлая, темная и системная тема.
- Импорт и экспорт резервной копии в JSON.

## Резервные копии и синхронизация

В настройках приложения можно экспортировать данные в файл `subtracker-backup.json` и импортировать их обратно. В резервную копию входят:

- настройки приложения;
- список подписок;
- правила оплаты;
- статусы подписок;
- даты создания и обновления.

Формат JSON версионируется, а приложение проверяет корректность данных перед импортом.

Также доступна синхронизация через Google Account. После авторизации настройки и подписки сохраняются в Google Drive пользователя. Позже эти данные можно импортировать обратно в приложение.

Доступна автоматическая синхронизация: приложение может автоматически экспортировать актуальные данные в Google Drive.
